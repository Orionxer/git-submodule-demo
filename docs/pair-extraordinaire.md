# GitHub Pair Extraordinaire Achievement

Pair Extraordinaire 用于记录通过 Pull Request 合并的共同创作提交。

## 触发步骤

1. 在提交说明正文后留一个空行。
2. 添加格式正确的 Co-authored-by: NAME <EMAIL> trailer。
3. 确保邮箱已关联共同作者的 GitHub 账号。
4. 通过 Pull Request 将该提交合并到默认分支。

参考：[GitHub Docs：创建多作者提交](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors)。

## 本地 Git 验证

本次补充提交由本地 Git 创建，并保留共同作者 trailer，以验证从本地提交到 Pull Request 合并的完整链路。

## 角色反转验证

本次提交由协作者作为主作者，并将仓库所有者列为共同作者，用于验证成就归属是否受作者角色影响。
